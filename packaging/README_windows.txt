symmetry-viewer  結晶・分子の対称性を学ぶ教材（Windows版）
==========================================================

Python などをインストールする必要はありません。
このフォルダの中に、動かすのに必要なものがすべて入っています。


■ 起動のしかた

※ ダウンロードした zip ファイルの中を直接開いて起動すると動きません。
   必ず zip を右クリックして「すべて展開」を選び、展開してできたフォルダの
   中で起動してください。

1. symmetry-viewer.exe をダブルクリックします。

2. 黒いウィンドウが開き、少し待つとブラウザで「解析モード」と
   「クイズモード」を選ぶ画面が表示されます。

ブラウザが開かないときは、黒いウィンドウに表示された
「http://127.0.0.1:（数字）/」のアドレスをブラウザで開いてください。

起動がブロックされた場合は、表示された検出名・警告内容を確認してください。
起動や操作の案内：
https://github.com/ono-knct/symmetry-viewer/blob/v1.0.0/docs/usage.md


■ 終了のしかた

黒いウィンドウを閉じてください。
ブラウザのタブを閉じただけでは終了しません。


■ 削除のしかた

プログラムを終了し、このフォルダを削除してください。
読み込んだ構造ファイルのコピーや解析結果は、Windowsの一時フォルダに保存されます。
自分で保存した画像やGIFは、必要に応じて別途削除してください。


■ 動作環境

- 64ビット版の Windows 10 / 11
- WebGL が使えるブラウザ（Edge、Chrome、Firefox など）

動作確認環境：Windows 11 Pro（64ビット、build 26200）。
