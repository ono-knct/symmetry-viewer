# 使い方

symmetry-viewerは、結晶・分子の対称操作を観察し、クイズで練習する3D教材です。
結晶16種・分子19種を収録しています。分子は対称性の学習を目的とした理想化モデルです。
構造の出典・加工内容・利用条件は [収録構造の出典](../examples/SOURCES.md) を参照してください。

## 起動と終了

### Windows版

1. ダウンロードした `symmetry-viewer-windows-x64.zip` を右クリックし、「すべて展開」を選びます。
2. 展開先の `symmetry-viewer.exe` をダブルクリックします。
3. ブラウザに表示される画面で「解析モード」または「クイズモード」を選びます。

終了するときは、起動時に開いた黒いウィンドウを閉じます。

### Linux版

ダウンロードしたファイルのある場所で、端末から実行します。

```bash
tar -xzf symmetry-viewer-linux-x86_64.tar.gz
cd symmetry-viewer
./symmetry-viewer
```

終了するときは、起動した端末でCtrl+Cを押します。
Windows版・Linux版とも、ブラウザのタブを閉じるだけではプログラムは終了しません。
動作環境の詳細は配布物の `README.txt` を参照してください。

### Web版

Web版のページをブラウザで開き、実行環境と教材データの読み込みを待ちます。
Pythonなどの追加インストールは不要です。終了するときはタブを閉じます。

Web版は収録例を対象としています。手元のCIF・XYZファイルを使う場合は配布版を利用してください。
必要なブラウザ機能や配信方法は [Web版の説明書](../web_static/README.md) に記載しています。

## 解析モード

1. 起動画面で「解析モード」を選びます。
2. 画面上部の「Crystal / Molecule」で結晶・分子を切り替え、「Select example...」から構造を選びます。配布版では「Import」からCIF（結晶）・XYZ（分子）ファイルを取り込めます。
3. 対称操作の一覧から操作を選びます。操作に応じた軸・面・中心が構造上に表示されます。
4. 「Play」で原子の動きを再生します。「Pause」で一時停止し、進行位置のスライダーで途中の配置を確認できます。「Reset」は再生を開始位置に戻します。

操作一覧の記号ボタンで、表示する操作の種類を絞れます。原子をクリックすると、その原子を選択できます。
ShiftまたはCtrlを押しながらクリックすると、複数の原子を選択・解除できます。

| マウス操作 | 3D表示の操作 |
|---|---|
| 左ドラッグ | 回転 |
| 右ドラッグ | 移動 |
| ホイール | 拡大・縮小 |

「Camera」の「Reset」で視点を初期状態に戻せます。
「Save」からPNG画像やGIFアニメーションを保存できます。

### 詳しい表示と操作の組み合わせ

画面上部の「Simple」を押すと「Advanced」に切り替わります。
Advancedでは対称操作の行列や式、操作を段階に分けた説明などを確認できます。
「Custom」では操作を作成・組み合わせ、構造の対称操作になるかを確認できます。

結晶では「Cell settings」でセルの種類を切り替えられます。切り替え後は読み込みの完了を待ってください。
「Structure details」では構造の情報や原子座標を確認できます。

## クイズモード

起動画面で「クイズモード」を開き、問題の種類を選びます。

| クイズ | 問う内容 |
|---|---|
| 操作あて | 原子の動きから、対称操作の種類や次数を答える |
| 合成 | 2つの操作を続けた結果に対応する1つの操作を答える |
| 移り先 | 指定された原子が移る先をクリックする |
| 点群あて | 表示された構造の点群を答える |

操作あて・合成・移り先では、構造選択画面で「Normal / Hard」が表示される場合に難度を選び、構造を選択します。
選んだ難度の問題がない構造は選択できません。難度の違いは画面内の説明で確認できます。

移り先クイズは結晶・分子の両方が対象です。結晶のHardでは、単位格子の外へ移動した原子に対応する、単位格子内の原子を選びます。

点群あてでは結晶・分子を選びます。結晶は続けて難度を選ぶと問題が表示されます。
回答後は正誤と解説を確認し、「解析モードで確認」から構造や操作を詳しく調べられます。

## 困ったとき

### 配布版でブラウザが開かない・接続できない

黒いウィンドウまたは端末に表示される `http://127.0.0.1:（数字）/` をブラウザで開いてください。
起動し直すと、アドレスの数字が変わることがあります。

### 構造が表示されない・読み込みに時間がかかる

ブラウザでWebGLが利用できることと、ハードウェアアクセラレーションの設定を確認してください。
Web版ではWebAssemblyも必要です。初回の読み込みやセルの切り替えには時間がかかる場合があります。

### クイズから解析へ戻ると再生位置が戻る

解析画面への読み込み中に再生位置を操作すると、読み込み完了時に元の位置へ戻ることがあります。
読み込みが完了してから操作してください。

### Windowsで警告が表示される・その他の問題

警告の場合は、表示内容と検出名を確認してください。解決しない場合は、使用した版、OS、ブラウザ、操作手順、エラーの内容を添えて [Issues](https://github.com/ono-knct/symmetry-viewer/issues) へ報告してください。
添付する画面やファイルに、個人情報や非公開の構造データが含まれていないか確認してください。

## 配布版の削除

プログラムを終了し、展開したフォルダを削除してください。
取り込んだ構造の作業用データはOSの一時フォルダに保存されます。
自分で保存した画像やGIFは、必要に応じて別途削除してください。
