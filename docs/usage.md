# 使い方

## 起動と終了

### Windows

1. ダウンロードしたZIPを右クリックし、「すべて展開」を選びます。
2. 展開したフォルダの `symmetry-viewer.exe` をダブルクリックします。
3. ブラウザでモード選択画面が開きます。

終了するときは、黒いウィンドウを閉じます。

### Linux

```bash
tar -xzf symmetry-viewer-linux-x86_64.tar.gz
cd symmetry-viewer
./symmetry-viewer
```

終了するときは、端末でCtrl+Cを押します。どちらのOSでも、ブラウザのタブを閉じるだけではプログラムは終了しません。

## 解析モード

1. 起動画面で「解析モード」を選びます。
2. 画面上部の「Crystal / Molecule」で結晶・分子を切り替え、例を選んで「Open」を押します。手元の構造は「Import」からCIFまたはXYZを開きます。
3. 「Operations」の一覧から対称操作を選びます。操作に応じた軸・面・中心が構造上に表示されます。
4. 「Animation」の「Play」で動きを再生します。スライダーで操作の途中の配置も確認できます。

一覧の上の記号ボタンで、操作の種類を絞れます。原子をクリックしてから再生すると、選んだ原子の動きを追えます。原子のない場所をクリックすると選択を解除できます。

| マウス操作 | 3D表示の操作 |
|---|---|
| 左ドラッグ | 回転 |
| 右ドラッグ | 移動 |
| ホイール | 拡大・縮小 |

「Reset camera」で視点を元に戻せます。画面上部の「Simple」を押すとFull表示に切り替わり、原子座標や操作の行列を確認できます。結晶では、対称操作の作成や合成も試せます。

## クイズモード

起動画面で「クイズモード」を開き、問題の種類を選びます。

| クイズ | 問う内容 |
|---|---|
| 操作あて | アニメーションで示された対称操作の種類 |
| 合成 | 2つの操作を続けて行った結果に対応する1つの操作 |
| 移り先 | 対称操作によって、指定された原子が移る先 |
| 点群あて | 構造全体の点群 |

操作あて・合成・移り先では構造を選びます。結晶の操作あてでは、続いて難易度を選びます。点群あてでは、結晶・分子を選ぶと問題が表示されます。
回答後に正誤と解説を確認できます。操作あて・合成・移り先では、動きも確認できます。

移り先クイズは分子が対象です。結晶の点群あてクイズは、表示した原子配置の対称性と結晶点群が一致する収録例から出題します。

## 困ったとき

### ブラウザが開かない・接続できない

黒いウィンドウまたは端末に表示される `http://127.0.0.1:（数字）/` をブラウザで開いてください。起動し直すと、アドレスの数字が変わることがあります。

### Windowsで警告が表示される

表示された警告内容と検出名を確認してください。解決しない場合は、OS・警告内容・起動手順を添えて[Issues](https://github.com/ono-knct/symmetry-viewer/issues)へ報告してください。

### 構造が表示されない

ブラウザでWebGLが利用できることと、ハードウェアアクセラレーションの設定を確認してください。

### NaClの読込方法によって動きが異なる

収録例のNaClを開く場合と、同梱の `Halite.cif` を読み込んで解析する場合では、一部の操作でアニメーションの経路と再生時間が異なります。

## 動作環境

Windows 10 / 11（64ビット）またはLinux（x86_64）と、WebGLに対応したブラウザが必要です。Linuxではglibc 2.27以上と、GLIBCXX 3.4.22以上に対応したlibstdc++が必要です。

動作確認環境：Windows 11 Pro（build 26200）、Ubuntu 26.04.1 LTS（x86_64）。確認日：2026年10月14日。

## アプリの削除

プログラムを終了し、展開した `symmetry-viewer` フォルダを削除してください。読み込んだ構造ファイルのコピーや解析結果は、OSの一時フォルダに保存されます。
自分で保存した画像やGIFは、必要に応じて別途削除してください。

同梱ライブラリのライセンス文書は、配布フォルダの `_internal/licenses/` にあります。
